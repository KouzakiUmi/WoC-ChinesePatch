# 西方奇幻小说级校对规格（Western Fantasy Novel Standard）

适用对象：`tl_work/chunks/**.tsv` 的对白与旁白、界面串，以及图片上的改写文字。
目标：让中文读者的感受等同于读一本**翻译引进版的西方奇幻小说**（如《魔戒》《时光之轮》《刺客学徒》的中译本），而不是"游戏机翻润色稿"。
本档与 `docs/proofreading-workflow.md`（流程）、`docs/characters.md`（角色语气）、`review/terms.tsv`（术语）配合使用；冲突时以更具体的那份为准。

判定分三档：

- **A 硬伤**：错译、漏译、占位符损坏、术语/专名不一致 —— 必须改。
- **B 规格问题**：语境出戏、翻译腔、语域错层、习语直译 —— 应该改。
- **C 文笔可选**：节奏、重复、用词磨光 —— 值得改，优先级最低。

---

## 1. 语境纯净：中世纪奇幻世界里不能出现"现代"

游戏世界没有电力、没有公司、没有官僚体系之外的现代组织。凡是把读者拉回 21 世纪的词，一律改写成等义的古风/西式说法。

| 类别 | 禁用（例） | 改成（例） |
| --- | --- | --- |
| 现代组织与管理 | 团队、协作、组队、项目、流程、进度、优先级、效率、绩效、考核、反馈、沟通、开会、报到、指标、资源、平台、上线 | 同伴、同行、一道、差事、次序、要务、先后、勤勉、考评、回话、商议、禀报、数目、产业、开启 |
| 现代科技/生活 | 手机、电脑、网络、信号、系统、数据、信息、打卡、快递、酒店、超市、电梯、汽车、火车、照片、电影 | （按场景改写：口信、消息、驿路、商栈、旅店、市集、车马、画卷、戏文） |
| 现代职场口吻 | "我们来对齐一下""这个方案""承担角色""解决问题的路径" | 按古白话对白重写 |
| 网络口语 | 稳了、溜了、绝了、上头、破防、整活、老铁、拿捏、无语了、emo、社死 | 换成朴素中文（心定、走开、好极了、涌上心头、失态） |
| 科幻词误入奇幻 | 相位转移、能量、模块、协议、频率、维度、扫描、激活、加载 | 凭空浮现、气力、机关、约定、动静、境界、探查、唤醒、翻开 |

> 注：**教程文本、系统菜单、设置项**属于"游戏外壳"，允许出现"点击 / 设置 / 存档"这类现代 UI 词，不受本条约束；但叙事层（旁白、对白、书页、信件、开场字幕）严格受限。

## 3. 西式称谓与礼数

- `sir / my lord / lady / dame / my lady` 不要平铺直译成"先生/女士"（5 处待确认见 `docs/characters.md`）。按身份取：骑士与贵族场合用**大人 / 阁下 / 领主大人 / 夫人**；对君主用**陛下 / 殿下**（若原文是 Majesty/Grace）；市井平辈才用"这位/朋友/老兄"。
- 对上级、君主、执政官必须用**您**与相应头衔；`docs/characters.md` 中各角色的 您/你 口径是硬约束（如豪尔对君主不可用"你"）。
- "God / Oh God / Thank God" 这类基督教残留：惊叹用**天哪 / 我的天 / 诸神在上**，信仰语境用**神 / 诸神**；避免直接"上帝"（本世界观是多神/泛灵）。
- 数量词与度量：西方风味用"几里路、一顿饭的工夫、一掌宽"，避免公制与现代计时（"公里""分钟"可用但不突出）。

## 4. 反翻译腔（欧化句法）

以下句式是"英文语法套中文"的标记，需改写：

1. **多层定语**："一个有着蓝色眼睛的高大的骑士的剑" → 拆句或用动词短语。
2. **"的"字连缀**：一句里"的"≥4 次、或相邻两个"的"。
3. **"是……的"框架**、"对于……来说"、"关于这件事"、"作为一个……"。
4. **被动硬译**："他被击败了"可留，但"门被打开了/被人们所遗忘"这类宜改主动或"遭/受"。
5. **代词粘连**：He/She 在中文里连续堆叠，宜用姓名、称谓或省略主语。
6. **插入语直译**："我——怎么说呢——很生气" 保留原文破折号风格时要通顺。
7. **习语直译**：`kick the bucket`、`spill the beans`、`it's not rocket science` 类必须意译；英语比喻若中文读来费解（"把猫从袋子里放出来"）要换成中文可感的意象，但**保留原文的意象类型**（仍用比喻，不改成说教）。
8. **语气词失衡**：旁白里"呢/吧/哦"过多会削弱文学感；对白里完全没有语气词则显得僵。

## 5. 分层语域（沿用 `docs/proofreading-workflow.md`）

| 层 | 判定 | 要求 |
| --- | --- | --- |
| 内心独白 | `speaker` 空 | 第一人称内省、书面但不文白；可用长句与破折号；禁网络口语与职场词；禁文言虚字（亦、皆、乃、遂、岂、故而） |
| 人物对话 | `speaker` 非空 | 按 `docs/characters.md` 的敬语、句长、口癖；禁文言腔与现代词 |
| 界面串 | `kind=strings` | 简短、无句末句号、保留 `%` 与 `[...]`、按钮名词化 |

**文白度**：奇幻小说的中文译笔是"**典雅的白话**"——可以有"着实、便、倒也、这般"，但不出现"甚、颇、亦、乃、何以、为之"成串的公文腔。角色若非学者/祭司，不用排比式书面语。

## 6. 文学性（C 级，逐句磨）

- **避免"很/非常/十分"堆砌**；能靠具体意象表达的不加程度副词。
- **避免"了"过载**：一句 2 个以内；心理描写里连续"了"会打断节奏。
- **重复用词**：相邻三句不重复使用同一形容词/动词（原文重复时中文可用近义词化解）。
- **节奏对齐原文**：原文短句急促（动作戏）中文也要短；原文长句铺陈中文才可铺陈。
- **省略号与破折号**：`...` → `……`（占 2 字宽）；`—` → `——`；`!?` → `！？`；`..`/`?.` 这类半吊子标点在中文侧要规范化。
- **中文标点全角**，引号用 `“”`，书名用 `《》`；英文引号 `"` 不得残留（引擎标签内除外）。
- **占位符与换行**：`{w} {nw} {p} {i} {b} [firstname]` 等数量、顺序须与原文一致（可按语感调整 `\n` 落点，但数量守恒）；标签内部内容不译。

## 7. 交付格式

每个 chunk 的问题清单（按严重度排序，条目上限 30 条，无问题则写"通过"）：

```
seq | 等级(A/B/C) | 类别 | 现译问题句 | 建议改法
```

类别取值：`错译` `漏译` `术语/专名` `现代词出戏` `翻译腔` `称谓` `语域` `文笔` `标点/占位符`。
