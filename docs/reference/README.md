## 使用约定
- **seq 引用**：`0009#3335` = `tl_work/chunks/dialogue/dialogue_0009.tsv` 的 seq 3335；`strings#483` = strings chunk；`zzz#L56` = `payload/game/zzz_chinese_language.rpy` 行号；`map288` 等 = 游戏内场景 ID（可用作 grep 键）。
- **剧透分层**：精校某 chunk 时，只可使用该剧情阶段已揭示的信息核对；lore.md §6 与 plot.md §5 为终局揭示，前期台词不得"预知"。
- **双轨结构**：chunks 0021-0026 是主线的平行重述（详见 plot.md 首部说明），与主线同 EN 场景按同型行处理。
- **uncertain 标记**：抽取时证据不足或文本未明言的条目，使用前需回原文复核。
- **更新纪律**：后续修复改动台词时，若改变了本篇事实（新设定、新分支、新结局），须同步更新对应条目并保持 seq 引用有效。
