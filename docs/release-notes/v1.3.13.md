# WoC 中文补丁 v1.3.13 (PC)

## Exodus 术语按 7 个概念分译（全 65 处 Exodus 原句逐处核对上下文）

`Exodus` 在原文里不是同一个词，而是一组同源派生的概念。此前 `review/terms.tsv` 只有一条 `Exodus→放逐` 的粗规则，无法区分下列形态——这既无法防止误改，也会把两个概念误判成「一字之差的异译」。本次逐处回读上下文后按形态固定。

| 英文形态 | 现行译法 | 判定依据 |
| --- | --- | --- |
| `The Blade of Exodus` | 放逐之刃 | 剑本身，全称出现，59 处 |
| `the Exodus` | 放逐者 | 0026#10020 福泰姆提议、#10023 瓦莱莎当场否决，是口头绰号故带引号 |
| `The Exodus Wielder` | 放逐者 | 0025#9931，全库**唯一大写** `Wielder`（另 12 处均小写），为执政团识别标签 |
| `Exodus wielder` | 放逐之刃的持有者 | 0010#3685 / 0014#5409，小写 = 描述性类别，非专名 |
| `Exodus training regiment` / `The Exodus Raid` | 放逐之刃训练计划 / 夺取放逐之刃的突袭 | 1216 上下文三条回复全在谈「接触剑」；Raid 的目的含测绘城堡，不能窄化成夺剑之战 |
| `An Exodus Theory` | 放逐之刃理论 | 0006#2184 为作者大纲标签块（同块含 `(Romance)`、`(Choice Dependent)` 制作批注） |

关键区分依据是**英文大小写即语义**：大写 `Wielder` 是专名化，小写是描述性。

## 正文修复（4 处）

- `0006#2184`「放逐理论」→ **「放逐之刃理论」**：与全库已定的 7 例一致
- `0025#9931`「放逐之刃的持有者」→ **「放逐者」**：`The Exodus Wielder` 为识别标签而非描述；`{i}` 斜体落点不变
- `0022#8431` 去掉「夺取放逐之刃的突袭」的引号：该事件非正式行动代号（英文三处大小写不一、当事人复述时弃用其名）
- `0022#8661` 去掉「放逐之刃」的引号：英文无引号

引号仅改这 2 处；另 3 处经查为合法用法（`strings_0001` 两处是 UI 选项引用，英文本身带引号；`0026` 两处是中文标示口头绰名的正确写法）。
