# WoC 中文补丁 v1.4 (PC)

## 工具层健壮性修复（游戏内容无改动）

v1.4 是纯工具与仓库维护版本（版本号自 v1.3.14 跨越）：**payload 68 个文件哈希不变**，游戏内容零改动；全部改动在安装器、翻译构建、校对工具与本地打包配置。

### 安装器 patch_tool.py（6 项）

- **卸载回退路径 `originals/` 死路径清除**：卸载仅用安装时生成的备份（游戏目录 `woc_zh_patch_backup/`，随游戏走），补丁包本身不含原版文件；无备份时提示「无法还原」并跳过
- **删除死代码 `CACHE_DIRS`**：从未被引用的遗留常量，删除以消除误导
- **删除 `find_game` 内冗余 `import re`**：模块顶部已导入，函数内重复导入无害但冗余
- **`do_check` 的 `except SystemExit` 保留具体退出消息**：打印 `exc.code`，不再吞掉具体错误原因
- **`do_install` 引擎版本校验前置到基线 sha256 校验之前**：引擎不符时先报引擎错，避免基线误报干扰排查
- **`do_uninstall` 的 `ok_hashes` 用 `e.get("original")` 兜底**：防 manifest 条目缺 `original` 字段时抛 KeyError

### 翻译构建 tl_tool.py

- **`cmd_build` 译文查表改为跨文件全局计数**：由文件内局部序号（`k+1`）改为 `seq_base` 累加 `len(dialogue)`，消除对「仅 script.rpy 含 dialogue」的隐式依赖；新增 chunk 序号与 template 条目数的一致性警告（不中断）

### 校对工具 review_tool.py

- **`cmd_apply` 写回前物化 `(kind, chunk, seq) → row` 索引**：消除每个 change 重读全表的 O(n²)

### 打包（本地构建 spec）

- **`WoC-ChinesePatch.spec` 与 `WoC-简体中文补丁.spec`**（本地构建用，被 gitignore）：`datas` 由整目录 `('payload','payload')` 改为从 `manifest.json` 精确读取（1 个 manifest.json + 68 个记录文件 = 69 条），排除 6 个本地运行产物（`log.txt`、`game/screens.rpyc.bak`、`game/cache/{bytecode,pyanalysis,screens}.rpyb`、`game/saves/persistent`）

### 收尾

- 删除 README.md 中 `originals/` 的文档遗留行
- 清理 `patch_tool.py` 与两 spec 的无害死分支
