### 开场字幕的渲染方式（重要）

```cmd
python tl_work\render_opening_caption_text.py zz11.png zz12.png
```
- 不带参数 = 重渲染 JSON 里的全部 15 张；带参数 = 只渲染指定文件
- 该脚本读 `tl_work\opening_caption_text.json`，以**游戏原版英文图的 alpha 通道**定位文字区
  （`SOURCE = C:\SteamLibrary\steamapps\common\winds-of-change\game\images`）
- 字体：霞鹜文楷 `LXGW WenKai Regular/Medium`（`bold` 字段用 Medium + 描边）、**10° 右倾斜体**、4× 超采样、超宽自动缩号
