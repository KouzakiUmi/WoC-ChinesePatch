# 图像编辑接口调用示例：b0010 书页试做

这份示例记录本次实际成功的 `functions.codex_connect_image_generate` 调用。**生成结果仅是图片资产/预览，不等于已经写入补丁目录**；必须另行取得原始 PNG、逐字核对并执行后处理。

## 1. 读取并选定输入图

先用 `functions.read_image` 查看 `tl_work/imagegen_inputs/books/b0010.png`。本次工具返回相邻的图片句柄：

```text
attachmentId=sha256:22ad0e295caec74053ec212d61d9bad9191bd8d48956df6521436a4c8cb2fecd
mediaType=image/png, width=1280, height=720, bytes=1033268, name=b0010.png
```

编辑已有图片必须传 `operation: "edit"`，并将读取结果所附**完整 attachment 对象**放进 `target.attachment`；不要仅凭文件路径或散列猜测目标，也不要将目标误放在 `references`。

## 2. 实际 Tool Call

```json
{
  "operation": "edit",
  "target": {
    "attachment": {
      "attachmentId": "sha256:22ad0e295caec74053ec212d61d9bad9191bd8d48956df6521436a4c8cb2fecd",
      "mediaType": "image/png",
      "width": 1280,
      "height": 720,
      "bytes": 1033268,
      "name": "b0010.png"
    }
  },
  "prompt": "请仅编辑这张英文书页图片上的文字，保持原图书本的大小、轮廓、视角、装饰、旧羊皮纸质感、光影和页边距不变，擦除全部英文，不得留下残字。左右页顶部均为标题「神秘日记」。左页按段落顺序写下以下全文，逐字准确，不增删，不改写：\n\n就是这一刻。我终于做到了。\n\n这十年来，我一直训练身体，以适应东冠的严寒。起初，我几乎走不了几英尺就得停下。可如今，我几乎能坚持一整天才需要折返。我知道，答案已近在眼前。\n\n东冠究竟有何目的？阿莱斯蒂亚还有多少未曾探索的疆域？\n\n我打算最后一次深入这些冰封群山，我知道自己会找到真相。明天我会与妻儿道别，把日记留在入口处。如果我能活着回来，接下来的篇章便会写满奇观与发现。届时，我们终将明白一切。\n\n右页中部仅一句「[其余页面均为空白。]」，无其他正文。左页下方页码「~1~」，右页下方「~2~」，不加署名。采用清楚可读的深褐黑色中文书法字，正文两页字体一致，自然换行、段落分明，不挤入边框。书本外的所有区域必须是完全均匀的纯 RGB(0,255,0) 绿幕，无渐变阴影杂点，也绝不可在纸张上覆盖绿色。输出尽可能高分辨率，以便缩至1280×720。尤其注意中文所有字均正确，不能出现伪字或乱码。"
}
```

上例通过 `functions.codex_connect_image_generate` 执行，返回 1672×941 PNG，原始结果 `assetId=img_4f682396ee5b41da8a03c7c91087e73e`。若对该**生成原图**继续编辑，应以 `target: {"assetId": "img_4f682396ee5b41da8a03c7c91087e73e"}` 指定它；不要将预览附件和原图混淆。每次调用后检查新结果，不能因调用成功就认定译文逐字无误。

## 3. 用于其他图片

按 [codex_work_order.md](codex_work_order.md) 替换输入图、标题与完整正文；书页以英文原图绿底为编辑目标，地图用指定英文原图，教程先准备绿底。工单中的中文正文优先于旧中文图片和模型 OCR。每张图须核对文字、布局、页码/署名、残留英文及绿幕边缘。书页取得生成 PNG 后调用 `finish_assets.py` 的 `key_book`，教程调用 `reconstruct_tutorial`，不要直接运行其旧的批处理 `process()`（它会写回其他旧图）。完成验证后再同步构建和 manifest。图片生成接口的返回值本身没有提供本地文件路径；GUI 结果卡片提供「下载原图」按钮。本次还核对了会话附件缓存中与返回 `sha256` 同名且哈希完全一致的 PNG 后复制到独立 staging；缓存属于运行环境实现细节，其他会话不能依赖该路径，优先以「下载原图」导出并核验尺寸、哈希。

**最终工作流硬性限制**：本次九张待修图片均仅以指定英文原图为编辑输入，用图像生成接口直接重绘全部中文。不得用本地脚本排文字，也不得在现有中文版上局部改字；脚本只用于生成前准备绿底、生成后等比缩放、绿键还原透明及校验。为降低中文字形伪影，提示词要求尽可能高分辨率输出（本次实际返回 1672×941），随后使用 LANCZOS 缩至 1280×720，并逐字核对成图。如文字有伪字、错漏，应从英文原图重新生成或在本次生成原图上用图像接口继续编辑，不用脚本修字。

教程图的英文 RGBA 原图须先将透明外围制成纯绿输入，再让接口重绘整图。还原 alpha 时，**不得直接把旧图的文字 alpha 叠到新图**：文字矩形先归一为邻近黑面板的 alpha=217，再依据新图白字亮度恢复新字形的 alpha；截图区域维持不透明。`tl_work/image_audit_repair_20260928/finish_generated.py` 只做缩放、绿键和这一 alpha 后处理，没有添加或改写任何字。
